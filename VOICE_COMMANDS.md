## Команды (естественный язык)

### 📅 Задачи и расписание
- "Запиши встречу с Сергеем в пятницу в 15:00"
- "Добавь задачу купить продукты на завтра"
- "Напомни мне позвонить в 18:00"
- "Что у меня по расписанию на сегодня?"
- "Отмени задачу планерка"
- "Перенеси встречу на 16:00"

### 🎯 Цели
- "Добавь цель: выучить испанский до декабря"
- "Отметь прогресс по книге 30%"
- "Какие у меня цели?"
- "Добавь подзадачу к финансовой цели"

### 💬 Общение
- "Привет" → ответ с расписанием
- "Спасибо" → вежливый ответ
- "Что ты умеешь?" → список команд

## STT (Speech-to-Text) варианты

### 1. 🏆 OpenAI Whisper (бесплатно, лучшее качество)
- `pip install openai-whisper`
- Работает локально, без интернета
- Русский отлично
- Минус: ~1 ГБ модель, требует ~4 ГБ RAM
- Вариант: модель `base` (~140 МБ, нормально)

### 2. 🥇 Google Speech Recognition (бесплатно)
- `pip install SpeechRecognition`
- Онлайн, бесплатно
- Простая интеграция
- Качество хорошее

### 3. 📱 Telegram Voice → OGG → STT
- Telegram присылает .ogg файл
- Конвертируем в .wav
- Распознаём через Whisper/SpeechRecognition

## Реализация

### Файлы:
1. `voice_commands.py` — парсер команд на русском
2. `stt_engine.py` — Speech-to-Text (Whisper/Google)
3. `telegram_bot.py` — бот с обработкой голосовых
4. `command_actions.py` — действия (добавить, обновить)

### Приоритет:
1. Telegram: голосовые → текст → команда → действие → ответ
2. ПК: микрофон → голосовая команда (позже)
